GitHub 토큰

토큰 만드는 법
  1. GitHub 설정 > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token
  2. Repository access: Only select repositories > bsjd
  3. Permissions > Repository permissions > Contents: Read and write
  4. 만든 토큰을 아래에 붙여 넣고 저장. 이 기기 브라우저에만 저장됩니다
